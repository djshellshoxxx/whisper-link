# whisper-link Wiki

Temporary, end-to-end encrypted chat for two people, in the browser, on GitHub Pages. No server, no
account, nothing stored. Start with the root README for usage and limits.

- [Architecture and Design Rationale](Architecture-and-Design-Rationale)
- [Codebase Map](Codebase-Map)

Read the Limits section in the README before relying on it: IP addresses are visible to each other,
there is no relay, and verification by phone or in person is required.
